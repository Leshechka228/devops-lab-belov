Цель работы

Получить навыки работы с Docker Compose, научиться управлять мультиконтейнерными приложениями, настроить взаимодействие между сервисами.

Требования

  • Мультиконтейнерное приложение (2+ сервиса)
  • Персистентный слой (volumes)
  • Docker Compose для оркестрации
  • CI/CD пайплайн с использованием docker compose

Architecture

Архитектура приложения

Приложение состоит из двух основных сервисов:

1. Frontend (Nginx)

  • Образ: nginx:alpine
  • Порт: 8282
  • Роль: Статический веб-сервер
  • Файлы: HTML, CSS, JavaScript

2. Backend (Python Flask)

  • Образ: python:3.9-slim
  • Порт: 8080 (внутренний)
  • Роль: REST API для отзывов
  • Технологии: Flask, JSON storage

Взаимодействие

Пользователь → Frontend (8282) → Backend API (8080) → JSON Storage (Volume)

Docker Compose

Все сервисы описаны в docker-compose.yml:

  • Сеть: belov-network
  • Volume: feedback_data
  • Зависимости: frontend зависит от backend
  • Health checks для мониторинга

Docker Compose

docker-compose.yml

version: '3.8'
name: devops-lab-b4lov

services:
  backend:
    build: .
    container_name: belov-backend
    restart: unless-stopped
    volumes:
      - feedback_data:/app
    networks:
      - belov-network
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8080/api/posts')"]
      interval: 30s
      timeout: 10s
      retries: 3

  frontend:
    image: nginx:alpine
    container_name: belov-frontend
    restart: unless-stopped
    ports:
      - "8282:80"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
      - ./:/usr/share/nginx/html
      - ./assets:/usr/share/nginx/html/assets
      - ./images:/usr/share/nginx/html/images
    depends_on:
      backend:
        condition: service_healthy
    networks:
      - belov-network

volumes:
  feedback_data:

networks:
  belov-network:
    driver: bridge

Команды управления

  • docker compose up -d - запустить стек
  • docker compose down - остановить стек
  • docker compose ps - статус сервисов
  • docker compose logs - просмотр логов
  • docker compose exec backend python backend.py - выполнить команду в контейнере
